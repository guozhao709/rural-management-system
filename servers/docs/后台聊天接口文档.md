# 后台聊天接口文档

## 基础信息

基础路径：

```txt
/admin/chat
```

鉴权方式：

```txt
Authorization: Bearer <adminToken>
```

权限要求：

```txt
role = super_admin
```

统一响应格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

常见错误：

| HTTP 状态码 | 说明 |
| --- | --- |
| 400 | 参数错误 |
| 401 | 未登录或 token 无效 |
| 403 | 权限不足 |
| 404 | 会话不存在 |
| 500 | 服务端异常 |

## 1. 获取会话列表

```txt
GET /admin/chat/conversations
```

说明：获取全部会话，按最后消息时间倒序返回。

请求头：

```txt
Authorization: Bearer <adminToken>
```

响应示例：

```json
{
  "code": 200,
  "message": "获取成功",
  "data": [
    {
      "conversationId": 1,
      "userId": 10,
      "username": "张三",
      "lastMessage": "您好",
      "lastMessageTime": "2026-06-09 12:00:00",
      "unreadCount": 2
    }
  ]
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| conversationId | number | 会话 ID |
| userId | number | 用户 ID |
| username | string | 用户名称，来自 users.name |
| lastMessage | string \| null | 最后一条消息内容 |
| lastMessageTime | string \| null | 最后一条消息时间 |
| unreadCount | number | 后台未读数量 |

## 2. 获取指定会话消息

```txt
GET /admin/chat/conversations/:conversationId/messages
```

说明：获取指定会话的全部消息，按时间正序返回。

路径参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| conversationId | number | 是 | 会话 ID，必须是正整数 |

响应示例：

```json
{
  "code": 200,
  "message": "获取成功",
  "data": [
    {
      "id": 1,
      "senderType": "user",
      "content": "你好",
      "createdAt": "2026-06-09 12:00:00"
    },
    {
      "id": 2,
      "senderType": "admin",
      "content": "您好，请问有什么需要帮助的？",
      "createdAt": "2026-06-09 12:01:00"
    }
  ]
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 消息 ID |
| senderType | string | 发送方，user 或 admin |
| content | string | 消息内容 |
| createdAt | string | 消息创建时间 |

## 3. 轮询获取新消息

```txt
GET /admin/chat/conversations/:conversationId/messages/after?lastMessageId=123
```

说明：前端轮询接口。传入当前前端已知的最后一条消息 ID，服务端返回该会话中 `id > lastMessageId` 的新消息。

路径参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| conversationId | number | 是 | 会话 ID，必须是正整数 |

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| lastMessageId | number | 是 | 最后一条已知消息 ID，必须是非负整数。传 0 表示从头获取 |

响应示例：

```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "list": [
      {
        "id": 124,
        "senderType": "user",
        "content": "你好",
        "createdAt": "2026-06-09 12:02:00"
      }
    ],
    "latestMessageId": 124
  }
}
```

无新消息响应：

```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "list": [],
    "latestMessageId": 123
  }
}
```

前端轮询建议：

1. 首次进入会话时先调用全量消息接口，记录最后一条消息的 `id`。
2. 定时调用本接口，将记录的 `id` 作为 `lastMessageId`。
3. 如果 `data.list` 不为空，将消息追加到页面，并用 `data.latestMessageId` 更新本地游标。
4. 本接口不会自动标记已读；需要已读状态时调用“标记会话已读”接口。

## 4. 管理员发送消息

```txt
POST /admin/chat/conversations/:conversationId/messages
```

说明：管理员向指定会话发送文本消息。

路径参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| conversationId | number | 是 | 会话 ID，必须是正整数 |

请求体：

```json
{
  "content": "您好，请问有什么需要帮助的？"
}
```

请求体字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| content | string | 是 | 消息内容，不能为空字符串 |

响应示例：

```json
{
  "code": 200,
  "message": "发送成功",
  "data": {
    "id": 10,
    "conversationId": 1,
    "senderType": "admin",
    "content": "您好，请问有什么需要帮助的？"
  }
}
```

行为说明：

- 插入一条 `sender_type = admin`、`message_type = text` 的消息。
- 更新会话的 `last_message`、`last_message_time`、`updated_at`。
- 不增加 `unread_count`。

## 5. 标记会话已读

```txt
PATCH /admin/chat/conversations/:conversationId/read
```

说明：将指定会话标记为后台已读。

路径参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| conversationId | number | 是 | 会话 ID，必须是正整数 |

响应示例：

```json
{
  "code": 200,
  "message": "标记已读成功",
  "data": {
    "conversationId": 1,
    "unreadCount": 0,
    "isAdminRead": 1
  }
}
```

行为说明：

- 将 `conversations.unread_count` 更新为 `0`。
- 将 `conversations.is_admin_read` 更新为 `1`。
- 更新 `conversations.updated_at`。
