# Frontend Technology Stack

本文档定义“智乡云”Frontend Application 的主要技术栈

具体 Dependency Version 以实际 `package.json` 和 Lockfile 为准。

## Core Stack

### admin

| 技术/工具                  |       版本 | 类型       | 主要用途                        |
| ---------------------- | -------: | -------- | --------------------------- |
| Vue                    |  ^3.5.41 | 前端框架     | 构建组件化、响应式的前端应用              |
| TypeScript             |   ~6.0.2 | 编程语言     | 提供静态类型检查，提升代码可维护性           |
| Vite                   |   ^8.2.2 | 构建工具     | 项目开发服务器、打包与构建               |
| Element Plus           |  ^2.14.5 | UI 组件库   | 提供表格、表单、弹窗等 Vue 3 UI 组件     |
| Pinia                  |    3.0.4 | 状态管理     | 管理应用全局状态及跨组件数据              |
| Vue Router             |    4.6.4 | 路由管理     | 实现 SPA 页面路由与导航              |
| Axios                  |  ^1.20.0 | HTTP 请求库 | 与后端 API 进行数据通信              |
| ECharts                |   ^6.1.0 | 数据可视化    | 绘制折线图、柱状图、饼图等图表             |
| Sass                   | ^1.103.1 | CSS 预处理器 | 增强样式编写能力，支持变量、嵌套等           |
