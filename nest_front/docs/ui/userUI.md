# 智乡云用户端 UI 规范

适用于普通用户的移动端页面。共享 Token 和基础原则见 [foundation.md](./foundation.md)。

## 设计目标

HarmonyOS 风格：简洁、自然、柔和、圆润、轻盈、清晰、可信。面向乡村居民及部分中老年用户，优先保证低认知负担、可读性和易操作性。

页面应以白色与浅灰为主，使用蓝色表达主要操作，业务色仅作局部识别。避免传统 Web/后台感、强科技感、粗边框、强阴影和密集分割线。

## 尺度与排版

| 项目 | 规则 |
| --- | --- |
| 圆角 | `8 / 12 / 16 / 20–24px`；普通卡片优先 `16px`，浮层可用 `20–24px`，Pill 为完全圆角。 |
| 间距 | 使用 `4 / 8 / 12 / 16 / 24 / 32px`；卡片内 `16px`，卡片间 `12–16px`，主要模块 `24px`。 |
| Display | `28–32px`，仅用于核心欢迎语、数字等特殊信息。 |
| Page / Section / Card 标题 | `24px` / `20px` / `17–18px`；分别使用 SemiBold 或 Bold、SemiBold、Medium/SemiBold。 |
| 正文与辅助文字 | 正文 `16–17px`；辅助文字 `14–15px`，避免大量 `12px` 或更小文字。 |
| 行高 | 短标题 `1.2–1.4`，正文 `1.5–1.6`，长文 `1.6–1.8`。 |

优先用字号、字重和间距建立层级，不以大量颜色或极粗字体区分信息。

## 组件与视觉

- **卡片：** 白色或极浅背景、大圆角、较宽松内边距；通过背景、留白和轻微阴影区分层级，避免粗边框和强阴影。
- **材质：** 允许少量半透明、Blur、柔和渐变或轻微光感；禁止大面积玻璃拟态、新拟态、霓虹、赛博风、强发光和强渐变。
- **图标：** 使用统一线性或 HarmonyOS Symbol 风格；Emoji 仅作少量情绪/内容辅助，不承担正式功能。图标默认随文字或 Primary，业务色仅用于必要识别。
- **业务色：** 仅用于图标、Tag、局部强调、状态标识和浅色背景；不得改变页面主背景、主要卡片、正文或主要交互的基础体系。

## 交互与可访问性

- 动效应轻、快、自然，常规 `150–300ms`，用于反馈、状态变化和空间关系；避免弹跳、旋转、呼吸灯、大幅位移和长时间动画。系统开启 Reduced Motion 或用户关闭动画时，减少非必要动效。
- 正文尽量不低于 `16px`，主要点击区域约不小于 `44 × 44px`。
- 关键操作和状态不能只通过颜色或图标表达；关键功能提供文字提示。避免浅灰小字、连续专业术语和低对比内容。

## 必须/禁止

- 必须保持宽松、圆润、低密度的移动端体验。
- 禁止使用 Admin 的小圆角、紧凑表格/表单和 PC 中后台交互模式。
- 禁止在页面内引入新的主蓝色或绕过全局 Token。
