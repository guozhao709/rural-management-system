# M08 农业知识种子：来源与摘要（P0）

更新时间：2026-08-20

## 使用边界

本文件是拟写入 M08「已发布公共知识」的数据备份，不是面向生产的处方或农药使用指南。内容均为对来源的简洁转述，供系统在作物识别、日常田间管理和风险提示中引用；具体播期、品种、肥水用量和病虫害防治必须以当地农技部门、登记标签、土壤检测与实时天气为准。

每条知识建议作为一条独立知识记录导入；其中同一类作物共用的管理原则可以关联多个作物。为避免不当用药风险，本批种子不写入农药名称、剂量或安全间隔期。

## 50 种作物的可入库摘要

### 粮食、油料和经济作物

| 作物 | 建议知识摘要 | 来源 |
| --- | --- | --- |
| 小麦 | 按苗情、墒情和目标产量实施测土配方与分期肥水管理；雨后及时排渍，病虫害按监测结果采取综合防控。 | S1 |
| 水稻 | 依据土壤和生育期科学施肥，注意田间水分调控；高温高湿或灾后应加强田间巡查和病虫监测。 | S1 |
| 玉米 | 关键生育期结合土壤与长势实施肥水管理；风雨后优先排水、清理沟渠并评估倒伏与病害风险。 | S1 |
| 大豆 | 提倡轮作或合理间套作，避免长期连作；根据土壤状况进行养分管理，干旱高温时优先保墒并持续监测。 | S2 |
| 花生 | 根据土壤肥力安排基肥和追肥，注意花针期、结荚期的水分与养分平衡；积水后及时排涝。 | S2 |
| 油菜 | 根据苗情和墒情施肥、排渍和防冻；油菜与非寄主作物轮作有利于降低部分连作风险。 | S2 |
| 马铃薯 | 结合土壤检测实施配方施肥，生长期保持适宜墒情、避免田间长期积水；及时巡田发现病害风险。 | S1 |
| 甘薯 | 选择排水良好的地块并重视整地起垄；生育期根据墒情补水、雨后排水，避免长期渍害。 | S1 |
| 高粱 | 选择适配当地积温和生育期的品种；苗期至灌浆期关注旱涝、倒伏和病虫害，按当地监测意见处置。 | S1 |
| 谷子 | 适期播种、合理密植并及时除草；雨季保持排水通畅，结实期关注鸟害、倒伏和病虫害。 | S1 |
| 绿豆 | 避免连作，适时中耕除草；花荚期重点防涝、防落花落荚，并根据监测开展病虫害综合防控。 | S2 |
| 芝麻 | 选择排水良好地块，苗期注意间苗定苗；开花结蒴期避免干旱和渍涝，雨后及时清沟排水。 | S2 |
| 棉花 | 根据土壤、苗情和目标产量平衡施肥；通过整枝等田间管理改善通风透光，并依据监测开展病虫害综合防控。 | S1 |
| 甘蔗 | 深翻整地、合理密植，生长旺期保障水肥供应；雨季及时排涝，宿根蔗应做好田间清理和更新管理。 | S1 |
| 茶树 | 重视园地排水、土壤有机质和树冠管理；采摘后结合树势与季节做好修剪、养分补充及病虫害绿色防控。 | S6 |

| 芹菜 | 苗期与旺长期保持均匀水分，雨季注意排水和通风；及时清理病叶，依据监测开展绿色防控。 | S3 |
| 洋葱 | 选择排水良好地块并合理轮作；鳞茎膨大期避免渍水，收获前适当控水并及时晾晒。 | S3 |
| 大蒜 | 选择无连作障碍、排水良好的地块；生长前中期保持适宜墒情，雨后排水，采收前逐步控水。 | S3 |
| 韭菜 | 合理留茬和分批采收，收割后结合长势补充养分；清除病残叶、避免积水并加强通风。 | S3 |
| 南瓜 | 合理密植、整枝和压蔓以改善通风；开花坐果期避免水分剧烈波动，雨后及时排水。 | S3 |
| 西葫芦 | 及时整枝、去老叶和疏果以保持通风透光；花果期少量多次补水补肥，避免高温高湿。 | S3、S5 |
| 西瓜 | 采用高畦或起垄栽培，雨季保持排水通畅；坐果后保持水分相对稳定，成熟前适度控水。 | S3 |

| 生姜 | 选择排水良好、避免连作的地块；夏季通过遮阴和保墒减轻高温影响，暴雨后及时排水并巡田。 | S3 |

## 导入建议

1. 每条记录的 `sourceName` 使用对应来源标题，`sourceUrl` 使用上方原始链接，`status` 为 `published`，`isGeneral` 为 `false`。
2. 分类可统一使用 `种植管理`；标签建议按“水肥管理、田间管理、防灾减灾、绿色防控、果园管理”等拆分。
3. 建议先由农业管理员审核本地适配性，再作为用户侧公开知识。尤其是表中未逐作物给出专门官方细则的条目，应在后续迭代补充当地农技部门或国家产业技术体系的专门资料。
