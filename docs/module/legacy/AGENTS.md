# Legacy Documentation Gate

- 本目录不是当前业务 Source of Truth，Agent 默认不读取。
- 仅在明确的迁移、兼容、历史核对任务或用户指定时按需读取。
- 引用时必须标明 Nest 或 Express 来源。
- Legacy 资料只能作为 Evidence，不得覆盖当前 Requirement、Design、Database Design 或 API Contract。
- 历史正文和不可变 Migration 可保留 `Mxx` 编号；当前路径、Contract 和新增代码不得使用。
